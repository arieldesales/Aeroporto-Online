✈️ Aeroporto Online — Plataforma de Turismo Interativo

Site de turismo interativo desenvolvido com HTML, CSS e JavaScript, com uma interface moderna para explorar destinos turísticos, conhecer diferentes culturas e simular reservas de viagens. O projeto reúne informações visuais, mapas interativos e recursos de navegação em uma única experiência.

🚀 Funcionalidades Principais
🌍 Exploração de Destinos: Apresentação de destinos turísticos com imagens, informações e detalhes sobre cada local.
✈️ Simulação de Reservas: Interface para selecionar aeroportos de partida, datas, voos, quantidade de passageiros e classe de viagem.
💺 Classes de Viagem: Opções de classe Econômica, Executiva e Primeira Classe.
💰 Cálculo de Preços: Atualização do valor estimado da passagem conforme a classe escolhida, a data e o número de passageiros.
🗺️ Mapa Interativo: Visualização da localização geográfica dos destinos selecionados.
🌤️ Relógio e Informações de Horário: Exibição de relógio digital e informações temporais na interface.
🖼️ Galeria de Imagens: Exibição de fotografias com visualização ampliada.
📜 Linha do Tempo Histórica: Apresentação de acontecimentos e informações históricas relacionados aos destinos.
📋 Minhas Reservas: Interface para consultar, acompanhar e cancelar reservas simuladas.
🎨 Interface Personalizada: Layout visual com animações, transições, elementos interativos e identidade visual voltada ao turismo.
🛠️ Tecnologias Utilizadas
HTML5: Estruturação das páginas e dos componentes da interface.
CSS3: Estilização, layout responsivo, animações e efeitos visuais.
JavaScript: Manipulação do DOM, navegação interativa, seleção de destinos e cálculo de valores das reservas.
💻 Como executar o projeto

Como o projeto utiliza tecnologias web, você pode executá-lo localmente sem precisar instalar dependências de backend.

Clone o repositório:
git clone https://github.com/arieldesales/Aeroporto-Online.git

Entre na pasta do projeto:
cd Aeroporto-Online

Abra o arquivo projeto.html diretamente no navegador ou utilize a extensão Live Server no Visual Studio Code.

Importante: confira se o arquivo JavaScript está nomeado como projeto.js, conforme a referência existente no HTML. Caso esteja como projeto (2).js, renomeie-o para projeto.js ou atualize o caminho no arquivo HTML.

📁 Estrutura do Projeto
Aeroporto-Online/
├── projeto.html       # Estrutura principal da aplicação
├── projeto.css        # Estilos e identidade visual
├── projeto (2).js     # Funcionalidades e interatividade
└── README.md          # Documentação do projeto

🎯 Objetivo do Projeto

Desenvolver uma experiência interativa de turismo que permita explorar destinos, visualizar informações geográficas e conhecer o funcionamento de uma interface de reservas de viagens, aplicando conceitos de desenvolvimento front-end.

Observação: as reservas e os preços apresentados fazem parte de uma simulação na interface, não representando necessariamente disponibilidade ou tarifas reais de companhias aéreas.
